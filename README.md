# Telegram → база знаний об автомобиле

**Telegram-бот:** в ветке `codex/telegram-rag-bot` добавлен отдельный серверный режим
для `@tg_channel_parse_bot`. Он принимает новые сообщения и документы, отвечает на
упоминания и изолирует базы разных чатов. [Запуск и развёртывание →](docs/TELEGRAM-BOT.md).
Локальный экспортёр и Windows-ярлыки работают как прежде.

Скачайте обсуждения своего автомобильного клуба и задавайте Codex вопросы с опорой
на сообщения, инструкции и документы. История, обработка файлов и поисковый индекс
хранятся на вашем компьютере. Платный API для эмбеддингов не требуется.

По умолчанию выбран клуб **FangChengBao**:
https://t.me/c/FangChengBaoClub/84505. Выгружается весь доступный форум со всеми темами.

## Запуск на Windows

1. Нажмите **Code → Download ZIP** на странице репозитория.
2. Распакуйте ZIP целиком в обычную папку, например `C:\cars\telegram-car-knowledge`.
3. Дважды щёлкните **Start.cmd**. Он подготовит Python и программу.
4. Получите **свои** `api_id` и `api_hash` на https://my.telegram.org/apps.
   Введите их в открывшемся окне, затем номер, код Telegram и пароль 2FA, если он есть.
5. Оставьте окно открытым. Программа скачает историю и документы, извлечёт текст и
   построит поиск по словам и смыслу. Повторный запуск продолжит прерванную работу.

Нужны Windows 10/11 **x64**, интернет и ваш доступ к клубу в Telegram. При первом
запуске скачиваются Python, библиотеки и публичные модели; объём может составить
несколько гигабайт. Далее основная обработка работает локально.

**[Пошаговая инструкция для владельца →](docs/START-WINDOWS.md)**

**[Готовое задание для вашего Codex →](docs/CODEX-SETUP.md)**

Для вопросов откройте распакованную папку как проект в Codex. Правила работы с
источниками уже находятся в `AGENTS.md`. Пример: «Поищи в моей базе, что делать,
если разрядился аккумулятор 12V. Моя машина: [модель и год]».

## Что скачивается и обрабатывается

- Все доступные сообщения, ответы, темы, подписи, ссылки и метаданные.
- По умолчанию только PDF/DOCX до **30 МиБ** и TXT/MD/CSV/JSON/LOG/YAML до **1 МиБ**.
- PDF с текстовым слоем, DOCX и текстовые документы; для сканированных PDF — локальное
  OCR русского, английского и китайского текста. Распознавание может ошибаться.
- Уже скачанные изображения, ZIP с документами, речь и выбранные кадры видео могут
  быть обработаны локально. Фото, видео, аудио, APK и ZIP автоматически не скачиваются.
- Внешние ссылки сохраняются, но программа не скачивает видео с YouTube и других сайтов.

При запуске через `Start.cmd` после успешной обработки удаляются скачанные файлы,
из которых не удалось получить пригодный текст. Сообщения и метаданные остаются.
Файлы с ошибками или превышенными ограничениями обработки сохраняются для повтора.
Кадры видео выбираются примерно каждые 30 секунд; это не полное описание видео.

## Прогресс и продолжение

- **Status.cmd** — состояние и счётчики.
- **Search.cmd** — поиск в готовой базе без Codex.
- **Update.cmd** — получить новые сообщения и обновить поиск.
- **Ctrl+C** в окне запуска — остановить; **Start.cmd** — продолжить.

Не запускайте несколько выгрузок одновременно. Ограничения Telegram соблюдаются:
если сервер просит подождать, программа сохраняет прогресс и делает паузу.
Готовность выбранных документов — `media_selection.complete`; `media_complete`
относится ко всем вложениям форума и при выборочной загрузке обычно будет `false`.
Полный критерий готовности и команды для Codex описаны в `AGENTS.md`.

## Где лежит результат

По умолчанию в `data/fangchengbao/`:

```text
archive.sqlite3                  оригиналы сообщений и метаданные, контрольные точки
media/                           выбранные скачанные файлы
processed/                       извлечённый текст, страницы/временные отметки, аудит
knowledge/messages.raw.jsonl      структурированная история
knowledge/messages.clean.jsonl    очищенный корпус
knowledge/topics/                сообщения по темам в Markdown
knowledge/cleaning.audit.jsonl    причины исключения из поискового корпуса
knowledge/index.sqlite3           поиск по словам
knowledge/embeddings/             локальные векторы поиска по смыслу
knowledge/report.json            итоговые счётчики
pipeline.log                     журнал работы
job.json                         состояние запуска
```

Очистка исключает из поискового корпуса служебные сообщения, пустые тексты, отдельные
эмодзи, короткие благодарности и точные длинные повторы внутри темы. Исходные сообщения
сохраняются. Дополнительные правила можно задать в `cleaning.json`.

Никому не отправляйте `.env`, `secrets/` и `.session`: это параметры и сессия доступа
к вашему Telegram. `data/` содержит переписку клуба и также остаётся локально.
В публичном репозитории этих данных нет; `.gitignore` исключает их из Git.

## Другой клуб и ручные команды

Измените `TELEGRAM_CHAT` и `TG_DATA_DIR` в локальном `.env`. Для разных клубов
используйте разные папки данных. Если имя из ссылки не найдено, команда `dialogs`
покажет точные названия и ID уже доступных групп; программа не вступает в группы сама.

В PowerShell из папки проекта после установки:

```powershell
.\.venv\Scripts\python.exe -m tg_knowledge.cli status
.\.venv\Scripts\python.exe -m tg_knowledge.cli search "сел аккумулятор 12V" --limit 8
.\.venv\Scripts\python.exe -m tg_knowledge.cli message 84505 --radius 3
```

При необходимости можно подключить локальный MCP-сервер по `mcp.example.toml`.
Для использования Codex в этом проекте регистрация MCP не обязательна.

На macOS/Linux установите [uv](https://docs.astral.sh/uv/getting-started/installation/),
затем `uv sync --frozen --python 3.12 --extra semantic --extra mcp --extra media` и
`.venv/bin/python -m tg_knowledge.setup`. Windows-ярлыки для этих систем не подходят.

## Разработка

```text
uv sync --frozen --python 3.12 --extra semantic --extra mcp --extra media --extra dev
uv run --no-sync pytest -q
uv run --no-sync ruff check src tests
```

Тесты не обращаются к Telegram и не требуют ключей или личной переписки.
GitHub Actions проверяет Windows и Linux, включая путь с пробелами и кириллицей.

Используются [Telethon](https://docs.telethon.dev/en/stable/basic/signing-in.html),
[EasyOCR](https://github.com/JaidedAI/EasyOCR),
[faster-whisper](https://github.com/SYSTRAN/faster-whisper),
[multilingual E5](https://huggingface.co/intfloat/multilingual-e5-small) и SQLite FTS5.
Получение Telegram API: [официальная документация](https://core.telegram.org/api/obtaining_api_id).
