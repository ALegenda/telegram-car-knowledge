# Пошаговый запуск на Windows

## 1. Скачать и распаковать

На странице репозитория нажмите **Code → Download ZIP**. Распакуйте **весь архив**
в папку, например `C:\cars\telegram-car-knowledge`. Не запускайте `Start.cmd` прямо
из окна ZIP: рядом с ним нужны остальные файлы проекта.

Откройте папку в своём Codex. Если хотите, чтобы он провёл вас по шагам, отправьте
ему задание из [CODEX-SETUP.md](CODEX-SETUP.md).

## 2. Получить собственные ключи Telegram

1. Убедитесь, что ваш Telegram уже имеет доступ к клубу FangChengBao.
2. Откройте https://my.telegram.org/apps в браузере.
3. Введите свой номер в международном формате, например `+7…`.
4. Код входа придёт в Telegram; введите его **на сайте**, не в чате Codex.
5. Откройте **API development tools**. Если приложение уже есть, используйте его.
6. Если его нет, заполните форму. Например:
   - App title: `Car Knowledge`
   - Short name: `carknowledge` (латиницей)
   - Platform: `Desktop`
   - Description: `Personal local archive and search of my car club`
7. Сайт покажет **App api_id** и **App api_hash**. Оставьте страницу открытой.

Это ключи приложения для вашего аккаунта; отдельно ещё будет вход в сам выгрузчик.
Чужие ключи и Telegram-сессии не нужны. Не отправляйте эти значения Codex или другим людям.

Если сайт не даёт создать приложение, покажите Codex только текст ошибки без ключей
и кода входа. Программа не может сама обойти отказ Telegram.

## 3. Запустить

Дважды щёлкните **Start.cmd**. Откроется обычное окно терминала.

Первый запуск установит uv, Python 3.12 и библиотеки. Администратор обычно не нужен.
Если загрузка прервалась, повторите запуск: уже скачанное используется повторно.

Вводите значения в этом окне:

1. `App api_id` — число с сайта.
2. `App api_hash` — длинная строка с сайта; ввод скрыт.
3. Номер телефона вашего Telegram.
4. Код входа, пришедший в Telegram; ввод скрыт.
5. Пароль двухэтапной проверки, если Telegram его запросит; ввод скрыт.

При скрытом вводе символы и звёздочки могут не отображаться — это нормально.
После ввода нажмите Enter. В дальнейшем вход сохранится локально.

Запуск включает обработку документов и удаление файлов, для которых успешно
подтверждено отсутствие пригодного текста. Сообщения и метаданные сохраняются.
При ошибках или превышении ограничений файл остаётся для повторной попытки.

## 4. Дождаться готовности

Оставьте окно открытым и отключите сон компьютера на время обработки.
Программа сначала сохранит историю всех тем, затем документы и текст из них,
после чего построит поиск по словам и по смыслу. Точное время зависит от размера
клуба, ограничений Telegram, скорости компьютера и интернета.

**Status.cmd** покажет текущее состояние. Полная готовность — `job.status=complete`
и все проверки из `AGENTS.md`; одно наличие индекса ещё не подтверждает полноту.

Журнал: `data/fangchengbao/pipeline.log`. При проблемах попросите Codex прочитать
последние строки журнала; не отправляйте ему `.env` или Telegram-сессию.

Для остановки нажмите **Ctrl+C**. Чтобы продолжить, снова запустите **Start.cmd**.
Не открывайте второй запуск параллельно. **Update.cmd** обновляет уже созданную базу.

## 5. Задавать вопросы

В чате Codex, открытом в папке этого проекта, напишите, например:

> Используй мою локальную базу FangChengBao. Моя машина: [точная модель, год,
> комплектация]. Поищи, что делать, если разрядился аккумулятор 12V. Прочитай
> исходные сообщения и контекст, приведи даты и ссылки. Отделяй опыт владельцев
> от инструкций производителя и не смешивай рекомендации для разных машин.

Программа сама не генерирует ответы: она даёт Codex найденные источники.
**Search.cmd** позволяет посмотреть результаты поиска без Codex.

## Если что-то пошло не так

- **«Чат не найден»**: имя в ссылке может отличаться от реального имени группы.
  Пусть Codex выполнит `dialogs` и выберет правильный ID с вами.
- **«Архив ещё не создан»**: выгрузка ещё не началась или не завершён вход.
- **Telegram просит ждать**: дождитесь конца паузы, не запускайте вторую копию.
- **Отсутствующая DLL**: Windows может требовать Microsoft Visual C++ Redistributable
  x64. Пусть Codex проверит ошибку и поможет установить пакет с сайта Microsoft.
- **Не скачивается модель**: нужен доступ к публичным моделям Hugging Face/GitHub;
  повторите запуск после восстановления интернета. API-ключ для этой задачи не нужен.

Историю, файлы сессии и ключи храните только на своём компьютере. Папку `data/` можно
резервно копировать локально, но она содержит переписку. Программа не пишет в Telegram
и не отправляет переписку в сервис эмбеддингов; обсуждение найденных источников в Codex
происходит в рамках вашего обычного чата с ним.
